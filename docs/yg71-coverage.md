## Test strategy

Existing PostgreSQL integration tests remain real and serial (`fileParallelism:false`),
including owner isolation, transaction rollback, API validation, MCP, recurrences,
Seoul date boundaries and all-day/timed scheduling. New React/jsdom tests exercise:

- Auth PKCE callback, refresh success/failure, logout and session privacy.
- PAT issuance/revocation errors; repo policy rejection; ticket prefix editing;
  briefing configuration, missing setup and owner-only sending.
- Capture text preservation and errors; AI suggestions and plan accept/dismiss errors.
- Todo drafts send changed fields only; date/time clears, completed dates, repeat
  rules, holds, durations and error responses; bulk restore and triage keyboard paths.
- Today, planning, board filters/menu moves/rollback and keyboard drag cancellation;
  all calendar modes, date basis, creation, failures, and undated tasks.
- Document tree, children, breadcrumbs, title/icon/body saving, failed-save retention
  and retry, archive/restore and drag cycle prevention; block commands, markdown,
  caret split/merge, paste, mentions, tables, toggles and unsafe inline links.
- Search request cancellation across owner changes, evidence, activity, review,
  real Remotion step navigation and the real app shell/hash routing.
- Tooling refuses unsafe/missing/unavailable DBs without printing connection secrets,
  and hook installation avoids writing a shared hooksPath.

Only fetch responses and unsupported platform APIs are controlled in UI tests;
components, hooks, editors, Radix controls, dnd-kit and Remotion are real. No product
code was rewritten for coverage. The local HTML report is `coverage/index.html`;
raw counters are `coverage/coverage-final.json` and `coverage/coverage-summary.json`.
Reports are ignored local artifacts, regenerated by `npm run test:coverage`.
Standalone Playwright scripts do not run with Vitest and contribute no coverage.

## Limits

This is global coverage, not a 90% per-file guarantee. Some drag geometry, browser
popover/layout behavior, process startup and third-party failure modes remain
uncovered. jsdom does not replace real browser layout/visual QA. Existing intentional
DB rollback tests log PostgreSQL errors; Remotion logs its license reminder and
jsdom's missing AudioContext warning. These are not unhandled test failures.

Local hooks can be bypassed with `--no-verify`, `HUSKY=0` or Git config changes;
remote enforcement needs separate CI/branch protection. Installation enables shared
`extensions.worktreeConfig`, but stores hooksPath only for this worktree; sibling
hooksPath was verified unchanged. Each worktree must install its own hooks/DB.
Run one suite at a time per worktree: DB and report output are shared within it.

Dependency audit remediation was outside this task: `npm ci` reported 18 findings
(9 moderate, 6 high, 3 critical). No `npm audit fix --force` or unrelated upgrades
were applied; those findings need a separate dependency review.
