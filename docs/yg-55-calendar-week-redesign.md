# YG-55 캘린더 주간 화면

2026-10-26 사용자 명시적 구현 인계. 기준 `8cb785c`, 전용 워크트리 `feat-yg-55-calendar-week-redesign`. 과거 문서 전용 지시는 이번 요청으로 해제. MCP get_todo 전문과 calendar-improvements 문서를 읽었으며 외부 기능정의 경로는 존재하지 않았다. AGENTS.md/.ai 및 상위 AGENTS.md는 발견되지 않았다.

## 구현 범위와 선택

- bare `#/calendar`는 기기와 무관하게 주간 기본. 명시 URL의 월/주/3일/일/목록은 유지한다. 주는 기존 일~토 계약을 재사용한다.
- 상단에서 중복 연월 라벨을 줄이고, 예정 없는 작업은 기본 접힘으로 그리드 아래(모바일은 기존 하단 패널 위치)에 둔다. 기존 TodoDetail이 선택 상세 역할을 유지한다.
- 날짜/종일 영역을 같은 시간표 스크롤의 sticky 헤더로 묶는다. 날짜를 누르면 하루 보기. 종일 4개 이상은 2개와 더 보기로 접어 별도 종일 세로스크롤을 제거한다. 전체 popover에서 상세/드래그 가능.
- 시간표는 단일 세로스크롤. 모바일 7일을 유지하며 가로 탐색, 시간 눈금은 왼쪽 고정. 기존 3일/일 보기도 즉시 선택 가능. 앱 셸은 수정하지 않는다.
- 연결된 겹침 그룹별 greedy lane: 3개 겹침 뒤 단독 작업은 전체 폭. 시간순으로 정렬된 기존 entries를 사용한다.
- 오늘 배경, 날짜 강조, 기존 분 단위 현재시간선 유지. 오늘을 포함하면 현재시각 90분 전, 다른 기간은 첫 일정 또는 08시 중 이른 시각 30분 전부터 표시한다. 모바일은 오늘 열까지 가로 이동한다.
- scheduledAt가 선택된 작업에만 estimateMinutes를 적용한다. 마감/ghost는 점선 시점 표시로 30분의 시각적 공간만 예약하며 종료시각을 만들지 않는다. 예정에 추정치가 없으면 기존 30분 시각 공간을 유지한다. 날짜 끝을 넘는 계획은 자정에서 잘라 보여 주며 다음 날짜의 가짜 일정은 만들지 않는다.
- 짧은 카드는 시간·제목을 한 줄에, 긴 블록은 시간 다음 줄에 제목을 표시한다. 긴 제목은 tooltip과 기존 상세에서 확인한다. 기존 우선순위 색과 마감 경고 색을 유지한다. 프로젝트 색 설정은 기존에 없고 원 티켓에서도 미확정이므로 새 매핑/설정은 추가하지 않았다.
